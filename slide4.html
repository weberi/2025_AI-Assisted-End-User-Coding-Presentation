Case Study

Can non-IT professionals independently develop small applications with the help of AI?

Participants:

  • Master's program Business Informatics: 21 (mandatory)
  • Bachelor's program Business Informatics: 12 (exercise)

Task Description

Participants create a simple digital application using a generally available AI (ChatGPT). The example project is a survey form.

The technical framework is kept as simple as possible:

  • The form is created as a simple HTML file and saved locally.
  • The form is dynamically controlled by JavaScript.
  • Incoming responses are collected in a Google Sheet.

Procedure

You prompt the AI with the task description.

For example: How can I design an HTML survey form? The form should be created as a simple HTML file and saved locally.

As a first result, you should receive HTML code that you save in an ordinary text file with the extension .html. You can open this with a browser.

You refine and expand your form step by step. Pay attention to good and user-friendly functionality, a sensible structure, and also good appearance.

Think of a suitable survey, that is, suitable questions.

  • Don't make it too easy (some variety – for example checkboxes and radio buttons), but also not too complicated (no unusual response options like dials, etc.).
  • If possible, include a dynamic question where different follow-up questions open depending on responses.

If you don't understand something, have the AI explain it to you.

Project Goal

You have created a working survey app!
"Full-stack Application"
  • Front-End: User interface where users interact and enter data - html and css
  • Logic Layer: processes the data - javascript
  • Back-End: stores the data permanently - Google Sheets
